Happ — это мобильное приложение, предназначенное для удобного управления прокси-серверами, работающее на надёжном ядре Xray. Приложение имеет простой и понятный интерфейс и набор полезных функций, что делает его удобным инструментом для управления подключениями.

**Основные возможности Happ:**

* Настройка прокси-серверов на основе гибких правил маршрутизации.
* Поддержка нескольких современных протоколов, включая:
  * **VLESS (Reality)**
  * **VMess**
  * **Trojan**
  * **Shadowsocks**
  * **Socks**

Happ обеспечивает конфиденциальность вашей сетевой активности, не собирая никаких данных; ваша информация остаётся только на вашем устройстве и никуда не отправляется.

Важно отметить, что Happ не предоставляет услуги VPN для покупки. Пользователи сами отвечают за получение или настройку собственных серверов. Также пользователи должны соблюдать законы своей страны при использовании приложения.

Чтобы сообщить о проблеме, используйте наш [сервис](https://issues.happ.su/)
